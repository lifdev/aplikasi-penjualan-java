# Aplikasi Penjualan (Java)

Aplikasi penjualan berbasis desktop yang dibangun menggunakan Java dengan NetBeans IDE.

## Cara Menjalankan

### Menggunakan NetBeans IDE

1. Clone repository ini:
```
   git clone https://github.com/lifdev/aplikasi-penjualan-java.git
```
2. Buka NetBeans IDE, pilih File > Open Project, lalu arahkan ke folder hasil clone.
3. Jika aplikasi terhubung ke database, pastikan database sudah dibuat dan konfigurasi koneksi (host, user, password) sudah disesuaikan di source code.
4. Klik Run Project.

### Menggunakan Apache Ant (tanpa NetBeans)

```
git clone https://github.com/lifdev/aplikasi-penjualan-java.git
cd aplikasi-penjualan-java
ant build
ant run
```
